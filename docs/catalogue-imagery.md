# Collection catalogue imagery

The catalogue is sample content. Existing local assets now replace all placeholder
covers. Names, IDs, categories, prices and product links are unchanged.

There are fewer available photographs than sample products. Covers labelled
**Illustrative photo** are representative furniture, not verified photographs of
the named model. **Room inspiration**, **Styling inspiration** and **Material
detail** identify contextual images. These labels remain editable through each
product's existing `badge` field. Some contextual images are necessarily shared;
replace them with merchant photography when available.

The Living Room collection uses twelve different cover assets. Other collections
use the available relevant furniture and room photographs rather than inventing
additional models or copying one photograph into multiple gallery slots.

Shopper galleries omit empty and duplicate URLs while preserving the original
catalogue indices. The editor still exposes all original upload slots. Catalogue
images use `contain` to show the whole piece inside a consistent landscape frame;
detail galleries, popups, wishlist actions and photo navigation retain their
existing behavior.
